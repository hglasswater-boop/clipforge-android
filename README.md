# ClipForge

Android向けの **MP4 / MKV 無劣化カット・結合ツール**。SMB共有上の動画を選択し、端末の作業用キャッシュへ安全に取得して処理後にSMBへ戻します。

## 現在の機能

- SMB 2.02〜3.11 接続 / フォルダブラウズ
- MP4 / MKV の複数選択
- Media3 / ExoPlayer による動画プレビュー
- タイムラインの場面サムネイル表示
- 左右のIN / OUTハンドルによるカット範囲選択
- 選択範囲だけのプレビュー再生
- キーフレーム情報が取得できる動画では、無劣化で切断可能な位置へ範囲をスナップ
- FFmpeg stream copy (`-c copy`) による無劣化カット
- 結合キューの ↑ / ↓ 並べ替え・除外
- FFmpeg stream copy (`-c copy`) による無劣化結合
- 結合前のストリーム互換性チェック
- SMBダウンロード / アップロードの進捗率表示
- 入力ファイルと同名の出力を禁止
- 既存のリモートファイルを上書きしない安全な一時名アップロード → rename
- 処理前の端末空き容量チェック
- 編集完了 / キャンセル時のローカル作業ファイル自動削除
- GitHub Actionsでユニットテスト・Debug APKビルド・Artifact公開

## カット操作

1. SMBブラウザで動画を1本選択します。
2. `プレビューしてカット範囲を選ぶ` を開きます。
3. 動画とタイムラインのサムネイルを見ながら左右のハンドルを動かします。
4. `選択範囲を再生` で結果を確認します。
5. `この範囲で無劣化カット` を実行します。

開始秒・終了秒の手入力は必要ありません。時刻表示は確認用です。

## 結合操作

1. SMBブラウザで2本以上の動画を選択します。
2. 結合キューの `↑` / `↓` で順番を調整し、不要な動画は `×` で外します。
3. 出力名を指定するか、空欄のまま `この順番で無劣化結合` を実行します。

## 無劣化カットの制約

ClipForgeは再エンコードを行わないため、映像の開始位置にはキーフレームの制約があります。キーフレームを取得できる場合は編集UIを実際に切断可能な位置へ合わせ、表示位置と出力結果の差を減らします。

コンテナやコーデックによってキーフレーム情報を取得できない場合は時刻ベースの範囲指定を許可しますが、実際の無劣化切断位置が前後する可能性があります。ClipForgeはこの場合も勝手に再エンコードしません。

## 結合の制約

映像・音声・字幕などのストリーム構成、コーデック、主要パラメータが一致しない動画は無劣化結合できません。ClipForgeは互換性がない場合に処理を停止し、品質を落とす自動再エンコードへフォールバックしません。

## SMBと原本保護

SMB上の原本をFFmpegへ直接渡して編集せず、一度ローカルの編集セッションへ取得します。処理結果は一時名でSMBへアップロードした後にrenameし、同名ファイルが存在する場合は処理を停止します。

プレビュー用に取得した動画はカット時にも再利用するため、同じ動画を二度ダウンロードしません。

## 技術構成

- Kotlin / Jetpack Compose
- Media3 / ExoPlayer 1.11.0
- Android Gradle Plugin 9.4
- compileSdk 36 / targetSdk 36 / minSdk 26
- `dev.ffmpegkit-maintained:ffmpeg-kit-min:8.1.7`
- `eu.agno3.jcifs:jcifs-ng:2.1.10`

## 開発

JDK 17 と Android SDK 36 が必要です。

```bash
gradle :app:testDebugUnitTest :app:assembleDebug
```

GitHub ActionsでもユニットテストとDebug APKビルドを実行し、成功したAPKを `clipforge-debug-apk` Artifactとして保存します。
