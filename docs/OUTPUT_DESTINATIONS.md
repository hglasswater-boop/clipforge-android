# 出力先

ClipForge のカット・結合結果の保存先は、入力元とは独立して選択できる。

## 方針

- `端末に保存`: Android の Storage Access Framework (SAF) の `ACTION_CREATE_DOCUMENT` を使い、ユーザーが端末ローカルまたは Android が公開する任意のドキュメント保存先を選ぶ。
- `XFilesでSMBに保存`: XFiles の `app.local1st.files.action.PICK_OUTPUT` を使い、SMB 上の保存先を選ぶ。
- どちらの経路でも、保存先選択後は取得した書き込み可能な `content://` URI を同じ処理サービスへ渡す。結合/カット処理側では保存先種別による分岐を持たない。
- 保存先選択をキャンセルした場合は処理を開始しない。
- XFiles が利用できない場合でも、端末ローカル保存は常に選択できる。

## 結合フロー

1. 2本以上の動画を結合キューへ入れる。
2. 出力名を確定する。
3. 保存先として `端末に保存` または `XFilesでSMBに保存` を選ぶ。
4. 選択した保存先ピッカーで出力先を確定する。
5. 返された URI に対して無劣化結合を実行する。

## カットフロー

カットも結合と同じ保存先選択を使う。出力 URI を取得した後の処理経路は共通とする。

## 受け入れ条件

- 結合時に端末ローカル保存を選択できる。
- XFiles が未インストールまたは利用不能でも端末ローカル保存を選択できる。
- XFiles が利用可能な場合は既存の SMB 保存も選択できる。
- 保存先選択で返された URI がそのまま既存の処理サービスへ渡される。
- 保存先選択のキャンセルでは結合/カットを開始しない。
